# Supplementary results

This folder holds the single curated result shipped with the repository:

- **`supplement_per_shot_four_datasets.html`** — the full per-shot (k = 1, 5, 10, 20)
  four-dataset comparison across all models and metrics. The main thesis text reports
  only the 20-shot slice of this table for readability; this file is its complete
  per-shot breakdown, showing the same ordering across the support range.

## Provenance / how it was built

It is generated by **`make_four_dataset_table.py`** (a copy of `scripts/make_four_dataset_table.py`),
which reads the per-run calibration/result exports and assembles the HTML table.

Input result directories (produced by the experiment pipeline, and **not** committed —
see the top-level README for how to regenerate them):

| Dataset            | Source results directory                 |
|--------------------|-------------------------------------------|
| DeepWeeds (DW)     | `kshot/results_calib`                     |
| BloodMNIST (BM)    | `kshot/results_calib`                     |
| Plant Seedlings V2 | `kshot/results_calib_fix`                 |
| SSL-Patches        | `kshot/results_calib_fix`                 |
| DeepWeeds long-k   | `kshot/results_deepweeds_longk_professor` |

The table is built for `SHOTS = [1, 5, 10, 20]`, uses the DD-CoMB naming, and excludes
the linear / expected-cross-entropy model rows (10 models retained). Once the result
directories above have been regenerated, re-run the generator to reproduce this file
exactly.
